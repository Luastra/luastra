# Luastra 0.3.0-alpha

This release adds Luastra-rendered static documentation and bounded typography.

- The website contains 360 standalone documentation pages generated by the
  existing Luau application and DOM renderer, preserving its design. Articles,
  navigation, metadata and the sitemap are available without JavaScript or Wasm.
- Lightweight reader controls provide themes, search, copy and responsive
  navigation. Live examples start a separate Luastra application inside the page
  only after the reader chooses Run example; changing themes preserves state.
- Orbit links open canonical documentation pages. Existing documentation hash
  bookmarks redirect to those pages. Website refinements include the original
  logo, complete center descriptions, and improved status badge spacing.
- `UI.TextStyle` supports declared local WOFF2 fonts, system fallbacks, bounded
  size, weight and line height on Text, Button, Link, TextInput, Code and CodeBlock.
  The typography example includes a redistributable font and its license.
- Source SDK contract 15 retains the phase5-alpha-8 runtime binary contract.

This is a documentation-specific prerenderer, not a universal application HTML
exporter or hydration implementation. Font loading follows browser CSS behavior;
physical-device typography fidelity is not established by web checks. Native
packaging and device verification retain their documented evidence boundaries.
Alpha APIs may change. Previous published releases and archives remain immutable.
