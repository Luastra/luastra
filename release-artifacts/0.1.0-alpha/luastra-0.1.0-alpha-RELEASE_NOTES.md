# Luastra 0.1.0-alpha

Public-source alpha release. This is pre-release software with bounded support and compatibility guarantees.

## Assets

Host archives use `luastra-sdk-0.1.0-alpha-<host>.tar.gz`. Download the release manifest and installer from the same GitHub Release, then run the installer.

Every asset is retained with `SHA256SUMS`; the manifest binds the host matrix, SDK content identities, SBOM, notices, license bundle, and installer.

## Retention

Published release assets are immutable. A correction receives a new version; existing bytes are never silently replaced.
