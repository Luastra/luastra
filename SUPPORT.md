# Luastra support

Luastra `0.1.0-alpha` is pre-release software. Community support is best-effort;
there is no service-level, response-time, production, or compatibility
commitment.

## Where to ask

- Use a GitHub issue for a reproducible defect or a bounded feature proposal.
- Use GitHub Discussions for usage and design questions.
- Use [`SECURITY.md`](./SECURITY.md) for suspected vulnerabilities; never place
  them in a public issue or discussion.
- For a private conduct report, contact the repository owner `@viachb-projects`
  through GitHub without exposing the incident publicly.

## What to include in a defect

- exact Luastra version or commit;
- development host and application target;
- minimal project or reproduction steps;
- expected and actual behavior;
- complete error text with credentials and personal paths removed;
- exact commands and whether the result came from web, simulator, emulator,
  physical device, desktop host, or CI.

Commercial support, hosted services, and paid plans are not implied by the
open-source license. Any future service will have separate terms and an
explicit support boundary.
