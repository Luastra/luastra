# 0.3.0-alpha development status

This release builds on 0.2.1-alpha. The source SDK is contract 15;
the runtime binary remains phase5-alpha-8. Published release archives are immutable.

## Static documentation

The website build executes the same Luau application and DOM renderer as the
interactive reference to generate complete HTML. Its 39 sections and 320 reference pages, plus
an index, include metadata, navigation, responsive reading styles and a sitemap.
Existing documentation hash routes redirect to their canonical HTML pages. The root no-script fallback links to the
reader. Staged generation preserves the previous successful website on failure.

This is a documentation-specific generator. It does not export arbitrary Luau
applications, load HTML fragments into the runtime, or hydrate existing HTML.
Those are independent future capabilities, not requirements for this release.

## Typography

`UI.TextStyle` supports six text components, local WOFF2 assets, fallbacks and
bounded size, weight and line height. The web build and local preview both serve
the generated CSS. Explicit size, weight and line height override component
defaults. See [the contract](typography.md) and the licensed typography example.

## Evidence and release boundary

Automated checks cover complete static content, links, deterministic output,
escaping, typed input rejection, font packaging and renderer asset validation.
Browser checks cover standalone documentation and live typography changes.
Theme, copy, search, menu and Orbit-return behavior are checked in the browser;
a 390px embedded viewport verifies mobile navigation. Physical-device typography fidelity remains outside this release's verified evidence.
