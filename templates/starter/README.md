# Luastra application

Application source and assets are user-owned. The initial Luastra-provided
starter fragments are available under 0BSD; see
`LUASTRA_TEMPLATE_LICENSE.txt`. You may replace, relicense or remove those
fragments in your application. The Luastra SDK and generated host output are
resolved by the CLI and are not copied into `src`.

```sh
luastra check
luastra test
luastra run
luastra build web
```
